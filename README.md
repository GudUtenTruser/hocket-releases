# Hocket

Hocket is a Mac app for running Claude Code and Codex side by side: your projects, conversations, agents, worktrees and pages in one place.

This repository only holds signed releases. There's no source code here.

## Install
Paste the [install prompt](INSTALL.md) into Claude Code or Codex. It sets up your Mac, installs Hocket, and checks each step.

You can also download the latest `.dmg` from [Releases](../../releases/latest), drag Hocket to Applications, and open it. Hocket updates itself from this public feed; updates need no GitHub login.

You need an Apple silicon Mac on macOS 13 or later (your agent's app may require a newer macOS). Hocket runs the agents you choose:
- **Claude:** Claude Code, signed in with your Claude account;
- **Codex:** the ChatGPT app for Mac, signed in.
