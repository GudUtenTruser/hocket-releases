# Hocket

Hocket is a Mac app for running Claude Code and Codex side by side: your projects, conversations, agents, worktrees and pages in one place.

This repository only holds signed releases. There's no source code here.

## Install
1. Download the latest `.dmg` from [Releases](../../releases/latest).
2. Open it and drag Hocket to Applications.
3. Open Hocket. It updates itself from here from then on.

You need a Mac with Apple silicon. Hocket runs the agents you already have:
- **Claude:** Claude Code, signed in with your Claude account;
- **Codex:** the ChatGPT app for Mac, signed in.

## Feedback
Use **?** → **Send feedback…** in the top-right corner of Hocket. Your issue is written up for you, and you see it before it's sent.
